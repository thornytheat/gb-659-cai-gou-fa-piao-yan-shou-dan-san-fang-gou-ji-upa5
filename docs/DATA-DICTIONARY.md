# 数据字典

- run_id：规则版本与输入 SHA-256 前 12 位组成的稳定批次标识。
- line_no：从 1 开始的物理来源行号，不因隔离或排序改变。
- business_key：本项目声明的业务唯一键，始终按字符串存储。
- reason_code：隔离原因的稳定英文编码。
- accepted：进入业务计算的记录数。
- quarantined：保留证据但不参与业务计算的记录数。
- 数值：金额、税额、用量和权重使用 Decimal；对外序列化为字符串。
- 时间：存储为带偏移的 ISO 8601，分桶使用半开区间。
- 空值：缺失键、空串和业务哨兵分别记录。
- 幂等：完整输入字节与规则版本相同则复用 run_id，不新增结果。
- ticket_key：单据类型与单号组成的票标识，同票多源补报归并到该键。
- digest：整票规范化内容的 SHA-256；金额半入到分、数量与税率去尾零后参与摘要，裁决与落账均绑定该摘要。
- base_version：裁决时声明的候选集版本，与当前版本不一致则按过期候选拒绝。
- adjudication_id：裁决幂等键，同键重试返回同次结果，不重复采信。
- outcome：裁决状态，PENDING_POST 已记录未落账、POSTED 已落账、VOIDED 因候选过期作废。
- 票状态：CLEAR 单候选生效；DISPUTED 争议未决，暂停该票勾稽；DECIDED 裁决生效。
